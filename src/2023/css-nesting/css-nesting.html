CSS Nesting

🎓 CSS nesting used to be a priviliege only for users of CSS pre-processors

🥰 Big part of why SASS and LESS became so popular

🥳 Now available in all browsers, no build tools required!

Simple Nesting

section {
    h2 {
        background: linear-gradient(to right, purple, hotpink);
        -webkit-background-clip: text;
        background-clip: text;
        -webkit-text-fill-color: transparent;
        width: fit-content;
    }
}
<h2>This is a h2 outside of the section!</h2> <section> <h2>This h2 is inside the section - and has awesome styling!</h2> </section>

Result

This is a h2 outside of the section!

This h2 is inside the section - and has awesome styling!

Complex Nesting

For most combined selectors, it's ok to use ampersand "&" - but also to omit it.

      ul {
        & > li { }
      }

      ⬇️⬆️

      ul {
        > li { }
      }

Complex Nesting

⚠️ For compound selectors using ampersand "&" is a must!

      div {
        .big { }
      }

      ⬇️

      div .big { }

      ----------------------------

      div {
        &.big { }
      }

      ⬇️

      div.big { }

⚠️⚠️ Make sure your users are running updated browsers!!! ⚠️⚠️
